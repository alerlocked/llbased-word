# Step 4: 创建计划文档

## 输出路径

`PRPs/requests/[feature-name].md`

## 文档结构

```markdown
# Implementation Plan: [Feature Name]

## Overview
## Requirements Summary
## Research Findings
## Implementation Tasks
  ### Phase 1: Foundation
  ### Phase 2: Core
  ### Phase 3: Integration
## Codebase Integration Points
## Technical Design
## Dependencies
## Testing Strategy
## Success Criteria
```

## 重要

计划应在 500-1000 行之间
