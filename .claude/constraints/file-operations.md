# 精准文件操作约束

> 目的：减少 token 浪费，提高文件操作效率

## 禁止操作

```yaml
禁止:
  - "glob **"           # 全盘扫描
  - "glob **/*.ts"      # 过于宽泛的模式
  - "glob **/*.{ts,js}" # 多后缀全盘扫描
  - "cat *.*"           # 批量读取
  - 无目的的 grep       # 没有明确目标
```

## 必须流程

```
1. 精确定位 → 2. 定向读取 → 3. 完成任务
```

### 正确示例

```bash
# 步骤1: 精确定位
grep "userAuth" --include="*.ts"    # 找到3个相关文件

# 步骤2: 定向读取
read src/auth/login.ts              # 只读取具体实现

# 步骤3: 完成任务
# 不读取无关文件
```

## 限制规则

| 规则 | 限制 |
|------|------|
| 单次对话最大读取文件数 | 10个 |
| glob 结果上限 | 20条 |
| grep 结果上限 | 30条 |
| 单文件读取行数 | 2000行 |

## 优先策略

1. **读取索引优先**: 先读 `CLAUDE.md` 中的文件索引
2. **grep 定位优先**: 先定位再读取
3. **增量读取**: 大文件分段读取
4. **缓存复用**: 同一对话中已读文件不重复读取

## 错误处理

```markdown
当文件操作超过限制时：
1. 停止并报告："文件操作超出限制，需要缩小范围"
2. 请求用户指定更精确的路径
3. 使用 Task 工具启动 Explore agent 进行深度搜索
```
