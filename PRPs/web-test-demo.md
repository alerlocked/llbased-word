# Web 测试流程演示

## 背景
用户想验证 Manager → Coder 的完整工作流程，并观察 Coder 的实际工作方式。

## 任务
在 localknowledgebase-word 项目中：
1. 启动开发服务器
2. 执行一个简单的 Web 测试（如：验证首页能正常加载）
3. 使用 Playwright 或其他 web 测试工具
4. 报告测试结果

## 观察要点
- Coder 是否使用 Claude Code 进行编码
- Web 测试使用什么工具（Playwright? Puppeteer? 其他?）
- 实际执行过程是否正常

## 验收标准
- [ ] 开发服务器成功启动
- [ ] Web 测试执行完成
- [ ] 报告包含：使用的工具、测试结果、执行过程观察

## 优先级
high

## piv 细化建议
这是单 piv 任务，一个 Coder 即可完成。
