# 技术债务清单 - localknowledgebase-word

## 问题

**PDF 解析效果不如 2 月底**

### 症状
- MinerU VLM 解析工艺文件 PDF
- 表格结构、文本、图片应 该保留不完整

### 诊断

1. **版本混乱**
   - 多个 PDF 解析相关文件
   - 配置分散在多处

2. **MinerU API 可能变化**
   - 当前版本: 2.7.6
   - 配置参数可能不匹配

3. **HTML 生成逻辑可能过时**
   - `generate_complete_html.py` 独立在外
   - 没有集成到主流程

---

## 解决方案

### 1. 统一 PDF 处理流程

创建一个统一的 `pdf_to_html.py` 脚本：
- 输入: PDF 文件路径
- 输出: 每页一个 HTML 文件
- 保留: 表格结构、 文本、 图片

### 2. 统一配置

在 `config.py` 中集中所有 MinerU 配置

### 3. 验证流程

1. 测试 MinerU 版本兼容性
2. 验证解析效果
3. 对比 2 月底的结果

---
