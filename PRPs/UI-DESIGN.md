# UI 设计文档 - 蓝白灰色调

**项目**: 智能工艺文件辅助编辑系统  
**设计版本**: v2.0 (蓝白灰)  
**更新日期**: 2026-03-07

---

## 1. 设计理念

### 核心原则
- **专业**：蓝色系传达专业、可靠
- **简洁**：白灰背景保持清爽
- **协调**：蓝白灰三色和谐统一
- **易用**：清晰的视觉层次和交互反馈

### 适用场景
- 工业生产环境
- 办公文档编辑
- 技术人员使用
- 长时间工作（护眼）

## 2. 色彩系统

### 主色调 - 专业蓝
```css
--color-primary: #1890FF;        /* 主色 - Ant Design 蓝 */
--color-primary-hover: #40A9FF;  /* 悬停 - 亮蓝 */
--color-primary-active: #096DD9; /* 激活 - 深蓝 */
--color-primary-light: #E6F7FF;  /* 浅蓝背景 */
--color-primary-bg: #F0F5FF;     /* 蓝灰背景 */
```

**使用场景**:
- 主按钮
- 链接
- 选中状态
- 焦点边框
- 品牌标识

### 辅助色 - 深蓝灰
```css
--color-secondary: #2C3E50;      /* 深蓝灰 */
--color-secondary-light: #546E7A; /* 浅蓝灰 */
```

**使用场景**:
- 次级标题
- 图标
- 辅助文字
- 边框装饰

### 背景色 - 白色系
```css
--color-bg-primary: #FFFFFF;     /* 纯白 */
--color-bg-secondary: #F7F9FC;   /* 浅灰蓝 */
--color-bg-tertiary: #EDF2F7;    /* 深灰蓝 */
```

**使用场景**:
- Primary: 页面主背景
- Secondary: 卡片背景、输入框
- Tertiary: Hover 状态、分割区域

### 文字色 - 灰度系
```css
--color-text-primary: #1A202C;   /* 深灰黑 */
--color-text-secondary: #4A5568; /* 中灰 */
--color-text-tertiary: #A0AEC0;  /* 浅灰 */
```

**对比度**: 所有文字色与白色背景的对比度 ≥ 4.5:1 (WCAG AA)

### 边框色 - 灰蓝系
```css
--color-border: #E2E8F0;         /* 标准边框 */
--color-border-light: #CBD5E0;   /* 浅边框 */
--color-border-dark: #A0AEC0;    /* 深边框 */
```

### 状态色
```css
Success: #48BB78;  /* 成功绿 */
Warning: #F6AD55;  /* 警告橙 */
Error: #F56565;    /* 错误红 */
Info: #4299E1;     /* 信息蓝 */
```

### 渐变色
```css
/* 主渐变 - 按钮背景 */
linear-gradient(135deg, #1890FF 0%, #40A9FF 100%)

/* 次渐变 - 装饰元素 */
linear-gradient(135deg, #2C3E50 0%, #546E7A 100%)

/* 强调渐变 - 高亮元素 */
linear-gradient(135deg, #00D9FF 0%, #1890FF 100%)
```

## 3. 组件设计

### 3.1 按钮

#### 主按钮 (Primary)
```jsx
<Button type="primary">
  保存
</Button>
```
- **样式**: 蓝色渐变背景 + 白色文字
- **悬停**: 变亮 + 上移 1px + 阴影加深
- **点击**: 下压 + 缩放 0.98
- **圆角**: 16px

#### 次按钮 (Default)
```jsx
<Button>
  取消
</Button>
```
- **样式**: 灰色背景 + 深色文字 + 灰边框
- **悬停**: 背景变深 + 边框变蓝
- **圆角**: 16px

#### 文字按钮 (Text)
```jsx
<Button type="text">
  更多
</Button>
```
- **样式**: 透明背景 + 灰色文字
- **悬停**: 浅蓝背景 + 蓝色文字

### 3.2 输入框

```jsx
<Input placeholder="请输入" />
```
- **默认**: 灰色背景 + 灰边框
- **悬停**: 边框变蓝
- **聚焦**: 白色背景 + 蓝边框 + 蓝色外发光
- **圆角**: 12px

### 3.3 卡片

```jsx
<Card>
  内容
</Card>
```
- **样式**: 白色背景 + 灰边框 + 浅阴影
- **悬停**: 边框变蓝 + 阴影加深 + 上移 2px
- **圆角**: 16px

### 3.4 抽屉

```jsx
<Drawer visible={true}>
  内容
</Drawer>
```
- **头部**: 浅灰蓝背景 + 灰边框
- **内容**: 白色背景
- **圆角**: 顶部 0，其他 16px

### 3.5 表格

```jsx
<Table dataSource={data} columns={columns} />
```
- **表头**: 灰蓝背景 + 深色文字
- **行悬停**: 浅蓝背景
- **边框**: 浅灰

### 3.6 标签

```jsx
<Tag color="blue">标签</Tag>
```
- **样式**: 无边框 + 浅蓝背景 + 蓝色文字
- **圆角**: 8px
- **内边距**: 4px 12px

## 5. 动画效果

### 5.1 过渡
```css
/* 基础过渡 */
transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1);

/* 弹性过渡 */
transition: all 0.25s cubic-bezier(0.175, 0.885, 0.32, 1.275);
```

### 5.2 动画
- **fadeIn**: 淡入 (0.25s)
- **slideUp**: 上滑淡入 (0.25s 弹性)
- **scaleIn**: 缩放弹入 (0.25s 弹性)
- **bluePulse**: 蓝色脉冲 (2s 循环)

## 6. 响应式设计

### 断点
```css
sm: 640px   /* 平板竖屏 */
md: 768px   /* 平板横屏 */
lg: 1024px  /* 小屏笔记本 */
xl: 1280px  /* 标准笔记本 */
xxl: 1536px /* 大屏显示器 */
```

### 适配策略
- **< 768px**: 单列布局，抽屉式侧边栏
- **768px - 1024px**: 双列布局，可折叠侧边栏
- **> 1024px**: 三列布局，固定侧边栏

---

## 7. 无障碍设计

### 对比度
- 文字与背景对比度 ≥ 4.5:1 (WCAG AA)
- 大文字 (≥18px 或 14px 粗体) 对比度 ≥ 3:1

### 焦点可见
- 所有交互元素都有明显的焦点环
- 焦点环颜色: 蓝色 + 外发光

### 键盘导航
- Tab 键可在所有交互元素间切换
- Enter/Space 可激活按钮
