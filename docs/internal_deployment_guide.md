# 内网部署指南

## 部署优先级说明

根据项目当前阶段，**功能性验证优先于部署方案完善**。本指南提供基础的内网部署能力，但重点确保核心功能正常运行。

## 快速部署步骤

### 1. 基础环境准备
```bash
# 安装基础依赖
pip install -r backend/requirements.txt
npm install --prefix frontend
```

### 2. 模型文件准备
- 将模型文件放置在 `./models/` 目录
- 确保目录结构正确：
  ```
  models/
  ├── deepseek-r1/
  ├── bge-large-zh-v1.5/
  └── bge-reranker-large/
  ```

### 3. 配置文件设置
```bash
# 复制配置模板
cp backend/.env.example backend/.env
# 编辑 backend/.env 配置必要的API密钥
```

### 4. 启动服务
```bash
# 后端
cd backend && python main.py

# 前端
cd frontend && npm start
```

## 功能验证清单

在进行完整部署前，请先验证以下核心功能：

- [ ] **主控Agent**: 工艺意图识别和任务分解
- [ ] **PDF解析**: 表格元素准确提取（≥97%）
- [ ] **RAG检索**: 工艺知识库检索
- [ ] **术语对齐**: 自然语言转标准工艺术语
- [ ] **合规检查**: 企业标准和行业规范检查
- [ ] **文档生成**: 标准化工艺文件输出
- [ ] **前端交互**: 助理面板和工艺编辑器
- [ ] **PDM集成**: 数据交换接口

## 部署简化策略

### 最小化部署
- 仅部署必需的组件
- 使用默认配置
- 跳过非核心功能的兼容性测试

### 渐进式完善
1. **第一阶段**: 确保核心功能在开发环境正常运行
2. **第二阶段**: 验证内网环境的基本部署
3. **第三阶段**: 完善国产化适配和高级部署特性

## 故障快速处理

### 功能问题
- 检查各子Agent的日志输出
- 验证模型文件路径是否正确
- 确认API密钥配置

### 部署问题
- 使用开发环境配置作为基准
- 逐步添加部署特定的配置
- 保持功能验证的连续性

## 后续完善计划

- **国产化适配**: Windows 7和麒麟系统兼容性
- **高级部署**: 容器化、集群部署、高可用
- **安全加固**: 网络隔离、访问控制、审计日志
- **性能优化**: 缓存策略、负载均衡、资源监控
