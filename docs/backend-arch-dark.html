⚙️ 后端技术架构

工艺文件辅助编辑系统 | Backend Architecture

应用层
🎨
Web 前端
React SPA，提供素材管理、文档编辑、AI 助手等交互界面
React 18 TypeScript Ant Design 5 Vite 5
↓
网关层
💬
Agent Controller
AI 助手对话入口，模式自动检测（问答/写作），流式响应
→ 调用 Agent 层：ProcessOrchestrator
→ 调用底层：DeepSeekService, HierarchicalContext
📁
Document Controller
文档管理、素材上传、项目 CRUD
→ 调用底层：VLService, DocumentProcessor
→ 数据库：SQLite (SQLAlchemy)
🔍
Search Controller
全文检索、语义检索、上下文匹配
→ 调用 Agent 层：SearchAgent
→ 调用底层：HierarchicalContext
↓
Agent 层
🎯 主控 Agent
🎭
ProcessOrchestrator
任务编排中心：意图识别 → 信息评估 → Agent 调度 → 结果整合
• IntentRecognizer - 意图识别
• InfoAssessor - 信息完整性评估
• TaskDecomposer - 任务分解
• IterationManager - 多轮迭代（max=3）
🤖 功能 Agent
✍️
Writing Agent
内容生成：大纲扩展、段落撰写、风格适配
→ 调用：DeepSeekService, HierarchicalContext
📝
Proofread Agent
文本校对：语法检查、术语规范、格式调整
→ 调用：DeepSeekService, 术语库
✅
Review Agent
质量审核：逻辑检查、合规性审查、专业性评估
→ 调用：DeepSeekService, 合规库
Writing Agent → Proofread Agent → Review Agent
🔎 检索 Agent
🔍
Search Agent
智能检索：关键词匹配、语义搜索、上下文关联
→ 调用：HierarchicalContext (4层渐进式披露)
↓
底层
👁️
VLService
视觉语言服务：PDF 页面 OCR、表格提取
MinerU VLM 本地 5-10s/页
Qwen-VL 云端 Fallback
📚
HierarchicalContext
分层上下文：渐进式披露，优化 Token 使用
4层架构
L0: 元信息 | L1: 索引 | L2: 按需加载 | L3: 精确检索
🧠
DeepSeekService
LLM 推理：文本生成、流式响应
DeepSeek API
OpenAI SDK 兼容 | stream=true
🛠️
Tools
工具模块：表格提取、文档处理、术语库、合规库
MinerUTableExtractor
占用矩阵算法 | colspan/rowspan
💾
Data Layer
数据存储：数据库 + 文件系统 + 向量索引
SQLite ORM
uploads/ 文件存储
embeddings/ 向量
